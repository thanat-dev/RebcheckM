# RebcheckM

แอปพลิเคชันตรวจสอบและติดตามงานบนมือถือ สำหรับการจัดการรายการตรวจสอบอย่างมีประสิทธิภาพ

## เอกสารการใช้งาน

- [คู่มือการใช้งานบนมือถือ](MOBILE_TUTORIAL.md) - คู่มือครบถ้วนสำหรับการใช้งาน RebcheckM บนอุปกรณ์มือถือ

## ฟีเจอร์หลัก

- สร้างและจัดการรายการตรวจสอบ
- ติดตามสถานะงานแบบ Real-time
- แนบไฟล์และรูปภาพ
- ระบบแจ้งเตือนอัจฉริยะ
- รองรับการทำงานออฟไลน์
- รองรับ Android และ iOS
